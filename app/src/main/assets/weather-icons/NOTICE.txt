These local VectorDrawables preserve the official Outlined 24px paths and
960px viewport. The XML theme tint is removed and the path fill is set to
black so Compose supplies the current UI color; the shapes are unchanged.

Symbols: sunny, clear_night, partly_cloudy_day, partly_cloudy_night, cloud,
rainy, weather_snowy, thunderstorm, foggy, air, weather_hail, weather_mix.

mapping are recorded in third_party/material-symbols/NOTICE.md.
